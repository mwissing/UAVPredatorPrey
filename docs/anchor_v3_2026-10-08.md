# Anchor v3 (2026-10-08)

Anchor v3 succeeds [anchor v2](anchor_v2_2026-10-06.md) as the reference
predator-prey pair. It is the first anchor trained with bootstrapped
time-outs and a rehearsal pool strong enough to prevent forgetting. It was
accepted by a rule fixed before the run, and it is the strongest checkpoint in
both roles of the 2026-10-08 league.

- Read-only bundle: `.pretrained_checkpoints/anchor_v3_2026-10-08/`
  (gitignored; README, MANIFEST.json, SHA256SUMS.txt, provenance, and
  evaluation evidence).
- Checkpoint: `current/agent_28800.pt`, sha256 `91c3f432...`. Evaluating
  the bundled copy reproduced the final own-matchup evaluation bit-exactly.
- Task `3v1-survival-soft-oob-teammate-vel-random-spawn-low-progress-v0`,
  preset `3v1-attention-critic-prey-attention-large-gru`, code `f68c3a5`.

## How it was made

1. **Start pair.** The anchor v2 predator plus the prey from arm B of the
   time-limit bootstrap A/B (2400 prey-only updates from anchor v2 with
   bootstrapped time-outs).
2. **Rehearsal pre-test.** A 75% pool with PFSP floor 0.3 removed forgetting
   completely, but cost 0.16 against the current opponent. By the
   pre-registered rule the run used a 60% pool with floor 0.3.
3. **Self-play.** The hysteresis scheduler with `toward_center` ran 12 x 1200
   updates (9 predator and 3 prey phases), keeping the catch rate near the
   band center. Recipe: FP32, LR 1e-5, KL 0.05, log-std floor -2, 8192 envs,
   seed 42.

Commands, pool files, and decision logic:
`artifacts/isaac/experiments/2026-10-07_anchor_v3_overnight/` (PLAN.md,
RESULTS.md), also copied into the bundle's `provenance/`.

## Evaluation

Deterministic, 1024 envs and episodes, seed 42, paired initial states.

| | anchor v3 | start pair |
|---|---:|---:|
| predator vs start prey | 0.562 | 0.367 |
| predator, reference prey mean | 0.869 | 0.878 |
| predator, held-out prey mean | 0.812 | 0.691 |
| prey conceded to anchor v2 predator | 0.312 | 0.367 |
| prey conceded, reference predator mean | 0.164 | 0.205 |
| prey conceded, held-out predator mean | 0.295 | 0.344 |

League (Bradley-Terry logits, Windows anchor prey = 0): predator +1.13
(anchor v2 +0.81), prey +1.09 (anchor v2 +0.50).

## Caveats

- The prey missed its strict criterion against the anchor v2 predator (0.312
  vs the required 0.287), although it improved on every measure and leads the
  league.
- Against the same prey, the anchor v3 predator is as strong as a single
  2400-update training phase (0.562 vs a 3-seed mean of 0.562) but forgets
  much less (reference 0.869 vs 0.803).
- It encloses the prey on the arena wall less often than earlier predators
  (0.112 vs about 0.17) and relies on individual interception. Coordination
  has not emerged.
- One training seed. The policies use the direct thrust-and-moment interface
  on the Crazyflie-scale model and must be retrained for the planned body-rate
  and FPV migration.
