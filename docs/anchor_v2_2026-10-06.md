# Anchor v2 — 3v1 predator-prey reference pair (2026-10-06)

The checkpoint, opponent pools, provenance and raw evaluations live in the
gitignored, read-only bundle `.pretrained_checkpoints/anchor_v2_2026-10-06/`
(MANIFEST.json, SHA256SUMS.txt). This page mirrors its README.

This pair succeeds the Windows anchor
`linux_migration_2026-07-11/current/agent_115200.pt` as the reference for
later experiments. On the fixed reference opponents, the predator is at least
as strong as the anchor predator and the prey is more robust than the anchor
prey.

- Checkpoint: `current/agent_28800.pt`
  (sha256 `40ebe94ed875036ada8752ee8656d9a823bcdeef9c064abe5c792d30f83db35f`)
- Task: `3v1-survival-soft-oob-teammate-vel-random-spawn-low-progress-v0`
  (legacy quadratic predator speed penalty)
- Preset: `3v1-attention-critic-prey-attention-large-gru` (recurrent MAPPO,
  entity attention, GRU actors, centralized critic)
- Runtime: `uavpredatorprey-isaaclab:f4aa17f-sim5.1.0-skrl1.4.3`

0.05, log-std floor -2, 8192 envs, seed 42, and time-outs treated as terminal

has been frozen since part 2. Full configs, histories and launch scripts are in
`provenance/lineage/`.

## Caveats

- The five reference prey were in the predator's training pool, so those
  numbers are in-distribution. The held-out July 19 prey Y5 fell from 0.695
  to 0.562 during the last run.
- Against its current prey the predator learned slowly: about +0.05 over
  7200 updates. Its policy std sits at the log-std floor in every action
  dimension.
- The pool files in `pool/` reference checkpoints by container paths
  (`/workspace/...`).

## Use

```bash
env -u DISPLAY -u XAUTHORITY /workspace/isaaclab/isaaclab.sh -p scripts/skrl/evaluate.py --headless \
  --task 3v1-survival-soft-oob-teammate-vel-random-spawn-low-progress-v0 \
  --agent skrl_mappo_attention_critic_prey_attention_large_gru_cfg_entry_point --algorithm MAPPO \
  --num_envs 256 --episodes 256 --seed 42 \
  --checkpoint .pretrained_checkpoints/anchor_v2_2026-10-06/current/agent_28800.pt
```

Pass the same path as `--checkpoint` to `hysteresis_curriculum.py` to
continue training from this pair.
